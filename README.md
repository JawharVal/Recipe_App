# 🍽️ LeGourmand – Мобильное приложение для обмена рецептами с генерацией на базе ИИ

## 📌 Обзор

Целью настоящего проекта является разработка мобильного приложения LeGourmand для платформы Android, которое позволяет пользователям удобно создавать, хранить, структурировать и делиться кулинарными рецептами, а также участвовать в челленджах и планировать питание.

В приложении реализована функция создания уникальных кулинарных рецептов с помощью искусственного интеллекта AI.

Приложение ориентировано на широкую аудиторию — от новичков до опытных кулинаров — и предоставляет как базовый функционал в бесплатной версии, так и расширенные возможности по подписке.

Проект включает три компонента:

* **Мобильное приложение** (Kotlin + Jetpack Compose) – пользовательская часть для Android.
* **Сервер (Backend API)** (Java Spring Boot + MySQL) – REST API с аутентификацией, подписками и интеграциями.
* **Админ-панель** (React.js) – веб-интерфейс для модерации пользователей, рецептов и челленджей.

---

## 🚀 Возможности

### 👨‍🍳 Для пользователей

* Регистрация и вход через **email** (с подтверждением по коду) или **Google Sign-In** (Firebase).
* Создание, редактирование, удаление и поиск рецептов.
* **AI-генерация рецептов** на основе списка ингредиентов (Yandex GPT API).
* Планировщик питания и список покупок.
* Создание личных **книг рецептов**.
* Участие в челленджах и таблица лидеров.
* Подписки на других пользователей, лайки и комментарии.
* Тарифы: **Free, Plus, Pro** (ограничения по количеству рецептов и AI-генераций).

### 🛠 Для администраторов

* Управление пользователями (профили, значки, избранное).
* Модерация рецептов и комментариев.
* Просмотр и обработка жалоб.
* Создание и модерация челленджей.
* Управление новостной рассылкой.
* Панель статистики и активности пользователей.

## 🏗 Технологии

### Мобильное приложение (Frontend)

* **Язык**: Kotlin
* **Фреймворк**: Jetpack Compose (Material 3)
* **Библиотеки**: Retrofit (REST), Firebase Auth, Coil (изображения), Stripe SDK (подписки), JWT Decode, Lottie

### Сервер (Backend)

* **Язык**: Java
* **Фреймворк**: Spring Boot
* **БД**: MySQL (Spring Data JPA)
* **Безопасность**: Spring Security + JWT
* **Интеграции**:

  * Yandex GPT API → генерация рецептов
  * Stripe → подписки и платежи
  * Sightengine → модерация изображений
  * SMTP (Spring Mail) → email-верификация
  * Firebase → Google Sign-In

### Админ-панель

* **Фреймворк**: React.js (SPA)
* **Навигация**: React Router
* **UI**: HTML5 + CSS3
